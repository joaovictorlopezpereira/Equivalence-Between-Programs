
A transição de implementações imperativas para especificações declarativas puras é uma estratégia essencial para a verificação formal de algoritmos. Este trabalho demonstrou a equivalência matemática entre os algoritmos Clássico e Modificado de Gram-Schmidt utilizando exclusivamente o raciocínio equacional sobre streams estabelecido por Hinze em \cite{Hinze2010}. Conclui-se que o cálculo de streams fornece o rigor necessário para tratar programas como expressões algébricas exatas. Essa abordagem preenche a lacuna semântica entre definições matemáticas contínuas e suas implementações computacionais, permitindo provar propriedades complexas de forma mais direta e estrutural.
