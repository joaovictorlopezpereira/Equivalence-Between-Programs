# Equational Reasoning for Proving Equivalence Between Programs

## Case Study: Classical and Modified Gram–Schmidt (with Streams)


### Description

This repository contains my final project for the **Functional Programming** course at the **Federal University of Rio de Janeiro (UFRJ)**.

The project investigates the use of **equational reasoning** to prove the equivalence between programs, using the **Classical** and **Modified Gram–Schmidt** algorithms implemented with **streams** as a case study.


## Repository Structure

* **`report/`** – Contains the project report, which presents the theoretical background, methodology, proofs, and main results.
* **`slides/`** – Presentation slides that complement the report.
* **`src/`** – Source code with two concise implementations of `dotproduct`, illustrating the concepts discussed in the slides.
